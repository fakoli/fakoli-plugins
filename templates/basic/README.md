# Basic plugin scaffold

An unfinished shared Agent Skill with native Codex and Claude packaging. Use Marketplace Manager to give the plugin and its skill a real name, metadata, and target checkout. Author and verify its intended workflow before distributing it.

Run `make test` to validate packaging from this marketplace checkout. If the scaffold is copied elsewhere, pass `MARKETPLACE_ROOT=/absolute/path/to/fakoli-plugins`. This check validates manifests and skill resources; it does not prove an unfinished workflow works.
